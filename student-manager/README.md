# REVERA 학생관리 (데스크 공용)

데스크 선생님들이 함께 쓰는 학생 관리 사이트입니다.
**구글 시트 1개 = 데이터베이스**, **Apps Script 웹앱 = 사이트** 구조라서 서버나 비용이 들지 않습니다.

## 기능

| 화면 | 내용 |
|---|---|
| 대시보드 | 진행 중 학생 수, 내 담당 학생, 14일 내 지원 마감, 밀린 할 일 / 30일 내 마감 목록 / 최근 상담 / 할 일 체크리스트 |
| 학생 | 검색(이름·학교·태그·학부모), 상태·담당자 필터, 학생 등록 |
| 학생 상세 | 상담기록 타임라인(작성자·수정자 표시, “다음 할 일” + 기한), 지원대학(전형·마감·진행상태·에세이 단계), 프로필 |
| 마감일정 | 전체 학생의 지원 마감을 날짜순으로 표시(D-day, 지난 미제출 건은 빨간색) |
| 선생님 관리 | (관리자) 계정 추가·비활성화, 관리자 지정 |

공동 작업을 위한 장치:
- **동시 수정 방지**: A 선생님이 화면을 연 뒤 B 선생님이 같은 항목을 먼저 저장했다면, A의 저장은 거부되고 안내 메시지가 뜹니다(덮어쓰기 방지).
- **변경로그**: 누가 언제 무엇을 만들고, 고치고, 지웠는지가 `변경로그` 탭에 자동으로 기록됩니다.
- 열어둔 화면은 2분마다 자동으로 새로고침됩니다. 상단 `↻ 새로고침` 버튼으로 바로 갱신할 수도 있습니다.
- 학생 삭제는 관리자만 할 수 있습니다. 일반 선생님은 상태를 `종료`로 바꿔서 보관합니다.

## 설치 (처음 한 번, 약 10분)

> **학원 공용 구글 계정**으로 진행하는 것을 권장합니다. 시트 소유자가 퇴사해서 계정이 삭제되면 사이트도 함께 멈춥니다.

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `REVERA 학생관리 DB`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 파일 3개를 붙여넣습니다.
   - 기본으로 있는 `Code.gs`의 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여넣습니다.
   - 파일 옆 **+ → HTML**을 누르고 이름을 `Index`로 지정(확장자 없이)한 뒤 `Index.html`을 붙여넣습니다.
   - (권장) ⚙️ 프로젝트 설정에서 **“편집기에서 appsscript.json 매니페스트 파일 표시”**를 체크한 다음, 편집기에 나타난 `appsscript.json`을 이 폴더의 파일로 바꿉니다. 시간대가 서울로 고정됩니다.
4. 상단 함수 선택에서 **`setup`**을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용하세요.
   → 시트에 `선생님 / 학생 / 상담기록 / 지원대학 / 변경로그` 탭이 생기고, 실행한 계정이 관리자로 등록됩니다.
5. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 아래처럼 설정합니다.
   - 실행 계정: **웹 앱에 액세스하는 사용자** ← 중요
   - 액세스 권한이 있는 사용자: **Google 계정이 있는 모든 사용자**
6. 배포 후 나오는 **웹 앱 URL**이 사이트 주소입니다. 북마크해서 쓰세요.
7. 사이트에 들어가서 **선생님 관리 → + 선생님 추가**로 선생님들의 구글 이메일을 등록합니다.
   등록하면 데이터 시트 편집 권한도 자동으로 부여되고, 구글이 해당 선생님께 공유 알림 메일을 보냅니다.

### 실행 계정을 “웹 앱에 액세스하는 사용자”로 하는 이유
일반 Gmail 계정을 쓰는 경우, “나(소유자)로 실행”으로 배포하면 접속한 사람이 누구인지(이메일)를 스크립트가 알 수 없습니다. 그러면 로그인 확인과 작성자 기록이 동작하지 않습니다.
이 설정에서는 각 선생님이 **본인 권한으로** 시트를 읽고 쓰기 때문에 시트 편집 권한이 필요하고, 7번 단계에서 이 권한이 자동으로 부여됩니다.

학원이 **Google Workspace(회사 도메인 메일)**를 쓰고 선생님 전원이 같은 도메인이라면, “나로 실행” + “도메인 내 사용자”로 배포해도 됩니다. 이 경우에는 선생님께 시트를 공유하지 않아도 됩니다.

### 선생님 첫 접속 시
처음 접속하면 구글 권한 승인 창이 뜹니다. 일반 Gmail 환경에서는 **“Google에서 확인하지 않은 앱”** 경고가 뜰 가능성이 큽니다. 학원이 직접 만든 스크립트이므로 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누르면 됩니다.

## 코드를 수정했을 때
Apps Script에서 코드를 고친 뒤 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 누르세요. URL은 그대로 유지됩니다.
(“새 배포”를 누르면 URL이 바뀌니 주의하세요.)

## 퇴사자 처리
1. 사이트의 **선생님 관리**에서 해당 선생님을 **비활성**으로 바꿉니다. 그 즉시 사이트에 접속할 수 없습니다.
2. **구글 시트 공유 설정에서도 그 계정을 직접 제거**하세요. 사이트와 별개로 시트 파일 자체를 열 수 있기 때문입니다.

## 주의사항
- 시트 탭 이름과 1행 머리글(영문)은 **바꾸지 마세요**. 열 순서는 바꿔도 되지만, 머리글이 바뀌면 해당 열을 읽지 못합니다.
- 데이터는 시트에 그대로 있으므로 엑셀로 내보내거나 백업하기 쉽습니다. **파일 → 버전 기록**으로 이전 상태를 복구할 수도 있습니다.
- 사이트는 데이터를 한 번에 모두 불러오는 방식입니다. 학생 수백 명, 상담기록 수천 건까지는 문제없을 것으로 예상하지만 실측한 값은 아닙니다. 느려지면 알려주세요.
- 학생·학부모 연락처 등 **개인정보**가 들어갑니다. 시트를 “링크가 있는 모든 사용자”로 공유하지 마세요. 개인정보 수집·이용 동의 등 법적 요건은 학원에서 따로 확인이 필요합니다.

## 개발자용
```
node dev/test-server.js     # 서버 로직 테스트 (가짜 시트로 실행)
node dev/build-preview.js   # dev/preview.html 생성 → 브라우저로 열면 샘플 데이터로 화면 확인
```
`dev/` 폴더는 테스트·미리보기 전용이며, Apps Script에 올리지 않습니다.
