# REVERA 학생관리 (데스크 공용)

데스크 선생님들이 함께 쓰는 학생 관리 웹사이트입니다. 외부 서비스 없이 독립적으로 동작합니다.

- **서버**: Node.js (Express)
- **DB**: SQLite 파일 1개 (`data/revera.db`). 백업은 이 파일을 복사하면 됩니다.
- **로그인**: 자체 계정(이메일 + 비밀번호). 관리자가 선생님 계정을 만들어줍니다.

## 기능

| 화면 | 내용 |
|---|---|
| 대시보드 | 진행 중 학생 수, 내 담당 학생, 14일 내 지원 마감, 밀린 할 일 / 30일 내 마감 목록 / 최근 상담 / 할 일 체크리스트 |
| 학생 | 검색(이름·학교·태그·학부모), 상태·담당자 필터, 학생 등록 |
| 학생 상세 | 상담기록(작성자·수정자 표시, “다음 할 일” + 기한), 지원대학(전형·마감·진행상태·에세이 단계), 프로필 |
| 마감일정 | 전체 학생의 지원 마감을 날짜순으로 표시(D-day, 지난 미제출 건은 빨간색) |
| 선생님 관리 | (관리자) 계정 추가·비활성화·비밀번호 초기화, 관리자 지정, **DB 백업 다운로드** |

공동 사용과 보안:
- **동시 수정 방지**: 다른 선생님이 먼저 저장한 항목을 덮어쓰려고 하면 저장이 거부되고 안내가 표시됩니다.
- **변경로그**: 누가 언제 무엇을 만들고, 고치고, 지웠는지를 DB의 `log` 테이블에 기록합니다.
- 열어둔 화면은 2분마다 자동으로 새로고침됩니다.
- 학생 삭제는 관리자만 할 수 있습니다. 일반 선생님은 상태를 `종료`로 바꿔서 보관합니다.
- 비밀번호는 scrypt 해시로 저장하고, 원문은 저장하지 않습니다.
- 같은 이메일로 로그인에 5번 실패하면 15분간 잠깁니다.
- 새 계정은 첫 로그인 때 비밀번호를 바꿔야 사용할 수 있습니다.
- 선생님을 비활성화하면 그 즉시 로그아웃됩니다.

## 내 컴퓨터에서 실행해보기

[Node.js](https://nodejs.org) 20 이상(LTS 버전 권장)이 필요합니다.

```bash
cd student-manager
npm install
npm run demo                          # 샘플 데이터가 든 데모 DB 생성
DB_PATH=data/demo.db npm start        # http://localhost:3000
# 로그인: admin@demo.test / demo-pass-1
```

Windows PowerShell에서는 `$env:DB_PATH="data/demo.db"; npm start` 로 실행합니다.

## 실제 운영 시작

```bash
npm install
npm run admin -- create 원장님이메일@example.com 원장님이름 "처음비밀번호8자이상"
npm start
```
접속한 뒤 **선생님 관리 → + 선생님 추가**로 선생님 계정을 만들고, 임시 비밀번호를 각 선생님께 직접 전달합니다.

### 환경변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 포트 |
| `DB_PATH` | `./data/revera.db` | DB 파일 위치. **클라우드에서는 반드시 영구 저장소(볼륨) 경로로 지정** |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME` | – | 계정이 하나도 없을 때 첫 실행에서 관리자를 자동 생성 (명령어를 쓸 수 없는 클라우드용) |
| `TRUST_PROXY` | – | `1`: HTTPS 프록시/클라우드 뒤에서 실행할 때 (접속자 IP 인식) |
| `COOKIE_SECURE` | – | `1`: 로그인 쿠키를 HTTPS에서만 전송 (HTTPS로 운영할 때 권장) |

## 어디에 띄울까 (배포 방법)

### A. 학원 PC에 설치 (내부망 전용)
- 항상 켜두는 PC 한 대에 위 “실제 운영 시작” 순서대로 설치합니다.
- 같은 와이파이/네트워크에 있는 선생님은 `http://그PC의IP:3000`으로 접속합니다. PC의 IP는 Windows에서 `ipconfig`로 확인합니다.
- 비용이 들지 않고 데이터가 학원 밖으로 나가지 않습니다.
- 대신 **학원 밖에서는 접속할 수 없습니다.** 이 PC를 인터넷에 직접 열어두는 것(포트포워딩)은 권장하지 않습니다. HTTPS가 없어서 비밀번호가 암호화되지 않은 채로 전송됩니다.
- PC가 고장나면 데이터도 잃을 수 있으니 **백업 다운로드를 정기적으로** 해두세요.

### B. 클라우드 (어디서나 접속)
`Dockerfile`이 포함되어 있어 Docker를 지원하는 서비스라면 대부분 그대로 올릴 수 있습니다. 확인해야 할 점은 아래와 같습니다.
1. **영구 저장소(볼륨/디스크)를 붙이고 `DB_PATH`를 그 안으로 지정**합니다. Dockerfile 기본값은 `/data/revera.db`이므로 볼륨을 `/data`에 연결하면 됩니다.
   볼륨이 없으면 재배포할 때마다 **모든 데이터가 사라집니다.**
2. **HTTPS 주소**로 운영하고, `TRUST_PROXY=1`, `COOKIE_SECURE=1`을 설정합니다.
3. 처음 한 번 `ADMIN_EMAIL`, `ADMIN_PASSWORD` 환경변수로 관리자를 만듭니다. 로그인한 뒤 비밀번호를 바꾸고, 이 두 환경변수는 지워도 됩니다.
4. 인스턴스(서버)는 **1개만** 실행합니다. SQLite 파일 하나를 쓰는 구조라 여러 대로 늘리면 데이터가 갈라집니다.

후보: Railway, Fly.io, Render(유료 플랜의 디스크), 일반 VPS(AWS Lightsail, 국내 클라우드 등).
각 서비스의 **현재 요금과 볼륨 지원 여부는 직접 확인**해야 합니다. 검색 예: `Railway volume pricing`, `Fly.io volumes pricing`.

## 백업과 복구
- **백업**: 관리자 화면 **선생님 관리 → 백업 파일 다운로드** (`.db` 파일 1개).
- **복구**: 서버를 멈추고, 받아둔 파일을 `DB_PATH` 위치에 같은 이름으로 덮어쓴 뒤 다시 시작합니다.
- 백업 파일 안에는 학생 개인정보가 들어 있습니다. 보관 장소에 주의하세요.

## 관리자 비밀번호를 잊었을 때
서버 콘솔에서 아래 명령을 실행합니다. 계정이 이미 있으면 관리자 권한과 비밀번호가 재설정됩니다.
```bash
npm run admin -- create 이메일 이름 "새비밀번호"
npm run admin -- list      # 계정 목록 보기
```

## 개발
```bash
npm test     # API 자동 테스트 (임시 DB 사용)
```
- `server.js`: 웹 서버, 로그인/세션, 요청 처리
- `lib/store.js`: DB 스키마와 업무 규칙(저장·권한·충돌 검사·로그)
- `public/index.html`: 화면 (빌드 과정 없는 단일 파일)
- `scripts/`: 관리자 명령, 데모 데이터
